# Movie Variability

This repository contains Python and R code accompanying a manuscript on variability between movies in inter-subject correlation (ISC) values and its consequences.

## Repository Structure

| Folder | Description |
| --- | --- |
| [`01_ISC`](01_ISC/) | Main ISC workflow, including mask creation, time-series extraction, ISC matrix creation, movie comparisons, and ANOVA visualization. |
| [`02_IS-RSA`](02_IS-RSA/) | IS-RSA workflow, including neural, behavioral, and control matrices plus result visualization and formatting. |
| [`03_control_analyses/equal_length`](03_control_analyses/equal_length/) | Control analysis using movies with equalized lengths. |
| [`03_control_analyses`](03_control_analyses/) | Additional control analyses. |
